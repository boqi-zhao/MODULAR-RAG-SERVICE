## 原职责与比较

chunk 读取固定成功 parse，负责边界、长度、重叠、顺序和来源，不能借此清洗原文或生成描述。
下游沿用块身份；重叠/重复段落的来源由切分过程传递，不靠首次字符串匹配猜测。

| 方案 | 原建议与取舍 |
| --- | --- |
| A 全文递归切分 | 接近旧实现，按字符/分隔符切分；页/图片映射要另做 |
| B 来源块感知切分 | 原倾向；合并短块、拆长块、保存区域，不保证多栏顺序；当前 MVP 缺所需块模型 |
| C 父子分块 | 小块召回、大块上下文；增加存储/去重/在线策略，未授权实施 |

原 B 倾向字符长度/重叠可配置、不跨页合并；跨页段落被切断是已知代价，不是当前决定。
模型 token 限制在编码前校验，图片语义不确定时不强行关联；长度、分隔符、跨页和关联规则当时均待评审。
