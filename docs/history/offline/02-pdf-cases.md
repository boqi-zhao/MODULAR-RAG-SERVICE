## 公开样本 R-01～R-07

来源/摘要见 [固定 20 页清单](04-doclaynet-sample-20.json)，原字节在本机 `data/samples/doclaynet/sample-20/`。
每份均为单页切片，因此解析页序是 1；原论文页码/印刷页码只作来源说明。

| 用例 | 输入 | 历史预期 |
| --- | --- | --- |
| R-01 图文财报 | 01 | 成功；Management Report、Sustained Positive Development of Sales and Earnings 在右上，六张照片及位置 |
| R-02 代码正文 | 04 | 成功；TABLE Statement、NO_MERGE；可无位图，不猜 SQL 语义 |
| R-03 表格文字 | 07 | 成功；Financial Summary、2011、2010；不要求行列结构 |
| R-04 图片定位 | 09 | 成功；Netted Balloon Systems 左上，两张气球照片右上/右下 |
| R-05 目录短块 | 10 | 成功；CONTENTS、Key terms、Basic usage；保留块位置，短块不拒绝 |
| R-06 扫描 | 19 | failed，疑似 OCR 观察值，保留扫描图/页记录，不把配套 JSON 的 194 个 cells 注入正文 |
| R-07 其余 14 页 | 其余 | 成功；完整页记录、非空原文字/位置和图片引用，不保证复杂顺序/全文语义 |

R-01/R-04 照片数经渲染核对，不用资源数量/标注框直接作答案；宽区域核对来源，精确位置另用控制输入。
历史预期是 19 页成功、19号页风险失败；若独立核对不符，先记录并重评审，而不是为全通过调阈值。

## 控制用例 R-08～R-18

这些编号不是公开样本编号，另造已知文字、像素、位置和页面设置的输入；错误注入单独标明。

| 用例 | 输入/操作 | 历史预期 |
| --- | --- | --- |
| R-08 多页中文 | 四页：中英文、空页、短标题、正文 | 成功；页序/文字归属正确，不因短页拒绝 |
| R-09 重复图片 | 第1页两位置、第2页一位置 | 三个实际出现及原矩形，字节可读，可去重资产但不能丢位置 |
| R-10 混合扫描 | 正常→扫描含标题/页码→正常 | 整份失败，第2页风险，保留第1/3页文字和扫描图 |
| R-11 旋转裁剪 | 90°、非零 CropBox、跨边界图片 | 原页码/矩形、完整图片，不要求展示转换 |
| R-12 不可读取 | 无效字节、需要密码 PDF | 区分读取失败和密码，不造空白成功 |
| R-13 局部故障 | 注入第二图字节/位置或某页文字失败 | 分别诊断失败并保留能继续获得的成果 |
| R-14 独立调用 | 同字节/配置重复调用，再换路径 | SHA 不变、内容/位置/诊断一致、不重复追加、不改第一结果 |
| R-15 扫描边界 | 面积0.79/0.80、字符79/80、重叠/旋转裁剪 | 0.80+79触发，0.79或80字不触发，同一坐标空间并集只算一次 |
| R-16 普通照片 | 满页照片无文字 | 原保守规则误拒，注明“疑似”而不是已识别扫描 |
| R-17 参数/引用 | 非法阈值、关闭后访问、坏图片注入 | 执行前拒绝参数；正常输出仍可读，坏引用失败 |
| R-18 范围/透明 | 内联、闲置资源、透明遮罩 | 实际出现全部记录、闲置资源不算出现、透明内容还原 |

控制矩形每边容差 1 point，重复图逐位置核对；文字分组不要求与标注/其他引擎一致。
R-14 独立调用不能代替存储/Runner 的失败恢复、强制执行或版本共存验收。

## 样本和证据规则仍有参考价值

固定公开输入先核对 SHA-256；缺失/改变是准备错误，不能静默跳过后宣称全套通过。
经独立核对的锚点和构造时已知输入决定预期，不能从被测输出倒推；公开 JSON 不能补被测 PDF 内容。
测试匹配可规范化空白，生产结果不因此改写。公开、自造、故障注入分别记录，解析单元验证不依赖 PG/网络/OCR。
跨机器公开回归需要固定字节和可复现获取步骤，未满足前不能当 CI 必需检查。
本机另有 9 份控制 PDF；仅文件名/摘要清单不能代替位置/文字/像素预期。
20 页质量获认可不等于所有后续策略获批，不用该样本发布通用准确率、业务效果或并发能力。
