# 身份与内容指纹

状态：设计或用例建议；具体批准范围见对应评审入口。

## 2. 身份规则

身份与内容校验和分开：路径属于来源元数据，校验和用于验证内容，两者不充当通用实体 ID。
下表中的随机 ID 建议使用带类型前缀的 UUID；具体编码规范在实现前冻结。

| 身份 | 建议规则 | 不变量 |
| --- | --- | --- |
| document_id | 接入时分配；更新必须显式指定已有文档 | 移动文件不改变文档身份；相同字节可属于不同文档 |
| document_version_id | 文档 ID 与原始字节 SHA-256 的摘要 | 同一文档相同字节可复用版本；原始文件永久可追溯 |
| artifact_id | 为每个候选产物预分配随机 ID | 强制重跑也分配新 ID；失败候选不能成为成功上游 |
| chunk_set_id | chunk 阶段的 artifact_id | 新的分块产物界定新的块集合 |
| chunk_id | 块集合 ID 与块内唯一局部键的摘要 | 所有编码和存储环节沿用，不另造存储 ID |
| execution_id | 每次实际执行分配随机 ID | 重试、强制执行都有独立尝试记录 |
| run_id | 一次批次任务及其执行计划的随机 ID | 绑定用户，包含多个文档项与阶段尝试 |
| batch_item_id | 批次内每个文档项分配随机 ID | 绑定文档版本，进度以项计数，阶段重试不重复计数 |
| corpus_snapshot_id | 一份不可变语料清单的随机 ID | 清单固定文档版本、块集合及块表示产物 |
| index_snapshot_id | 一次索引组合构建的随机 ID | 命名空间独立，绑定唯一语料快照 |

局部键在块集合内唯一，可用稳定遍历序号；chunk_id 不依赖增强后的文本或文件路径。
父块和子块使用同一套身份规则，记录 parent_id 与是否参与检索，父子关系必须无环。
原始文件摘要一致时可以去重保存字节，但不合并两个逻辑文档的身份。
重新上传是否属于已有文档由调用方指定；相同路径不自动推断更新，避免路径复用误关联。

### 2.1 内容指纹与复用

执行指纹包含阶段名、契约版本、实现版本、完整有效配置、模型/Prompt 版本、固定输入引用及校验和。
摘要采用 SHA-256；结构化数据使用明确版本的规范化序列化，字节内容按原始字节计算。
规范化需固定键顺序、编码、数值处理和默认值展开；实现前定义并验证测试向量。
有顺序的输入保持顺序；集合型输入排序，禁止把具有顺序意义的数据任意排序。
运行时间、执行 ID 和日志不进入指纹；影响输出的环境、随机种子和依赖版本必须记录。
指纹用于寻找可复用候选，不保证 LLM 或远程模型输出确定，也不代替产物 ID。
模型只有可变别名时记录别名与实际解析信息；无法锁定版本时标记复现限制并默认禁用自动复用。
复用必须验证成功状态、契约兼容、所有文件校验和及隔离范围；范围包括用户权限及语料/实验归属。
强制执行绕过复用，即使指纹相同也生成新产物；不承诺并发同指纹只执行一次。
