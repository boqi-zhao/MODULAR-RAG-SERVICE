# 阶段依赖与原文定位

状态：设计或用例建议；具体批准范围见对应评审入口。

## 3. 阶段契约与依赖

每个 Stage 接收具名、带版本的输入引用和有效配置，输出候选产物及结构化校验结果。
禁止读取隐式“最新”文件；禁止原地改写上游。所有必需输入缺失或类型不兼容时在执行前拒绝。
下表为建议依赖，箭头表示产物依赖；可选阶段是否启用必须在任务计划中显式确定。

| 阶段 | 固定输入 | 完整输出与关键校验 |
| --- | --- | --- |
| parse | 原始文档版本、来源格式与解析器配置 | 统一解析单元、文本、结构、来源定位、图片引用、解析器信息和诊断 |
| chunk | parse 产物 | 块集合、顺序、父子关系、原文证据范围；ID 唯一且引用完整 |
| refine（可选） | chunk 产物 | 清理后的块表示、变更记录；保留块身份和原文映射 |
| enrich（可选） | refine 或 chunk 产物 | 增强块表示、结构化字段、完整模型请求/响应及诊断 |
| image_register（有图时） | parse 中的图片字节与引用 | 图片资产清单、内容摘要及引用映射；成功前图片字节可读取 |
| caption（可选） | 选定块表示、image_register 产物 | 图片描述、请求/响应、合成后的块表示及映射 |
| dense_encode | 语料快照及其选定块表示 | 每块向量、维度、模型版本和编码输入摘要 |
| sparse_encode | 同一语料快照及其选定块表示 | 每块词项、频次、长度、分词器/词典版本 |
| vector_write | dense 产物、语料快照、候选索引 ID | 隔离向量索引、写入清单、后端版本与完整性结果 |
| bm25_build | sparse 产物、语料快照、候选索引 ID | 完整 postings、N/DF/平均长度、参数及完整性结果 |

主链为 parse → chunk → [refine] → [enrich] → [caption]；方括号阶段可关闭。
image_register 从 parse 分支，启用 caption 时与主链汇合；无图时可输出明确的空图片清单。
从最终块表示收集完整语料快照，再分支执行 dense_encode → vector_write 与 sparse_encode → bm25_build。
关闭可选阶段时计划直接绑定前一个产物，不创建伪装成执行结果的占位产物。
refine/enrich/caption 不增删块、不改变 parent_id 和证据范围；需要重分块时建立新的块集合。
Caption 文本与基础文本分开保存；合成规则固定，重跑读取 caption 之前的表示，避免重复追加描述。
语料快照显式列出参与检索的 chunk_id；编码阶段不得静默丢弃失败块，必须失败或形成显式的新语料快照。
Dense/Sparse 必须覆盖相同的 chunk_id 清单及块表示输入摘要；仅 ID 一致而文本版本不同也拒绝组合。

### 3.1 原文定位

每块保留 document_version_id、parse artifact_id 及一个或多个证据范围。
解析文本范围采用 Unicode 码点的左闭右开区间；范围必须明确所指文本流与段落/页对象。
另存原始来源定位，例如页码、版面区域或结构节点；增强文本不覆盖原始证据文本。
相同解析快照上的不同分块方案可按范围比较；更换解析器后不能直接比较两个文本流的偏移。
跨解析方案复用标注需映射回固定原始文档版本，映射算法及精度另行设计。
