# PDF parse 已确认决定

## 已确认决定

- 需要 OCR 或图片提取/定位失败时，保留已产生的部分结果和诊断，供查看、排查和后续重跑。
- 全扫描件可能没有可提取文本；仅保存实际得到的结果，不伪造缺失内容或未知的位置。
- 不完整解析默认标记为 failed，部分产物仅用于诊断与重跑，不能作为正常下游输入。
- 疑似扫描正文采用保守阻断：判 failed，诊断注明“疑似需 OCR”，接受一定误拒；[扫描风险规则](pdf-parse/03-scan-policy.md) 已评审通过，默认按每页图片覆盖率至少 80% 且非空白字符少于 80 判断。
- 首批由 PyMuPDF 统一提取文本和图片，定位粒度为页码与文本块/图片矩形区域。
- 首批直接保留原始坐标用于解析排查；原文高亮展示与展示坐标转换后置，不要求额外输出展示转换信息。
