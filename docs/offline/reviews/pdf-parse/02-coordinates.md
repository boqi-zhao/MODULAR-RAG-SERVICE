## 2. 已确认的位置与文本约定

- 页序从 1 开始，表示当前输入 PDF 中的位置；DocLayNet 单页切片均为第 1 页。
- DocLayNet 原文页序与印刷页码只作为样本来源说明，不覆盖当前 PDF 页序。
- 使用 PyMuPDF 返回的未旋转页面坐标，左上原点、向右/下递增，单位 point（1/72 英寸）。
- 矩形为 `(x0, y0, x1, y1)`；直接保存库返回的原始位置，不要求额外保存用于展示的旋转、裁剪或转换信息。
- 保存 PyMuPDF 提取出的文字块和顺序。解析阶段不删除或改写文字、不生成图片描述，也不额外调整双栏等复杂页面的阅读顺序。
- 此处的文字块是解析库识别的一段文字，还不是后续 RAG 分块得到的 chunk。
- 不强行把块拼为一个全局文本流；字符偏移等后续需要的规则留在相应范围评审。
- 同一张图片在多个位置出现时，每次都记录页码和坐标。图片文件可以去重保存，但不能丢失任何一次出现的位置。
- 制作图片位置已知的测试 PDF，检查提取的坐标是否正确；四条边各允许最多 1 point 的误差。
- 对公开 PDF 样本，先人工选定要检查的文字，并确认它所在的页码和大致区域；测试检查这些文字是否正确提取、位置是否正确，不要求文字块边界与 DocLayNet 标注完全一致。
- 提取 PDF 页面上实际显示的位图（如照片、截图），包括只显示一部分的图片，不因 PDF 内部存储方式不同而漏掉；如果无法取得图片数据或位置，本次解析标记为失败并说明原因。
- PDF 中由线条和形状绘制的图形，本轮不作为图片文件提取；图片带有透明部分时，提取结果必须保留透明效果。
