## 5. 补充控制用例

R-08 等是测试用例编号，不是 DocLayNet 的样本编号；下载的 20 个公开 PDF 都是单页。
这些用例需要另外准备测试数据：制作多页、重复图片等 PDF；部分用例可以复用文件，只改变配置或调用方式；另一些需要让提取步骤故意报错。
制作时记录已知文字、图片像素、放置位置和页面设置，用这些记录确定预期，不能根据被测解析器的输出倒推答案。
公开 PDF、自制 PDF 和模拟错误的测试分别标记；模拟错误测试不能代替真实 PDF 测试。

| 用例 | 已知输入/操作 | 已确认预期 |
| --- | --- | --- |
| R-08 多页/中文/空页 | 另行制作的 4 页测试 PDF，非 DocLayNet 样本 08；依次为中英文正文、空白页、短标题页、另一页正文 | 成功；四条页记录，指定中文正确提取，空页仍是第 2 页；每段文字归属正确页面，短标题页不被误判失败 |
| R-09 同图多次出现 | 同一已知图片在第 1 页两个位置、第 2 页一个位置 | 三个出现记录各有正确页/矩形，字节均可读取；去重存字节可选，但来源不能去重丢失 |
| R-10 混合扫描与继续处理 | 正常页 → 扫描正文页（另含短文本标题/页码）→ 正常页 | failed；第 2 页风险记录准确，保留第 1/3 页文本及第 2 页图片，不因提取到标题就通过 |
| R-11 旋转/裁剪页面解析 | 已知文字和图片，90° 旋转及非零 CropBox；图片部分跨裁剪边界 | 正确提取文字与图片，保留页码和原始矩形；不要求展示坐标转换或高亮映射 |
| R-12 不可读取 | 明确无效 PDF 字节、需要密码的有效 PDF | failed；区分格式/读取失败与需要密码；没有伪造空白成功结果 |
| R-13 局部提取故障 | 多图多页正常输入；可控注入第二张图片字节提取失败、位置获取失败、某页文本提取失败 | 分别测试；failed，诊断能定位；保留之前成果及能继续获得的其他成果；不吞错宣称成功 |
| R-14 重复调用 | 相同固定字节/配置解析两次，再对相同字节更换来源路径 | 输入 SHA-256 不变；内容/位置/诊断语义一致，不重复追加；第一份返回结果不被第二次修改 |
| R-15 扫描规则边界 | 已知图片覆盖率 0.79/0.80；非空白字符数 79/80；多张重叠图片 | 覆盖率 0.80 且 79 字触发；0.79 或 80 字不触发本规则；重叠部分只计一次，按实际可见区域计算 |
| R-16 普通照片误拒 | 满页纯照片、无文本，独立标注其实际为照片 | 按保守规则 failed；诊断是“疑似”，不能断言已识别扫描文字；记录这类已知误拒边界 |
| R-17 配置与引用校验 | 非法阈值；正常结果关闭解析文件后访问；损坏图片字节的受控故障 | 非法配置执行前拒绝；正常字节和定位仍可读；已检测到图片无效则 failed，不输出可用假引用 |
| R-18 图片范围与透明度 | 内联位图、无实际出现的图片资源、已知透明遮罩 | 内联图正常记录；无实际出现的资源不计图片出现；透明内容可还原，不能只保留失去遮罩的主图冒充完整 |

控制图片矩形按已知插入位置核对，每条边容差为 1 point；重复图片验证三个具体位置，不能仅验数量。
文字块不要求解析器之间分组相同：以固定锚点、正确页序和对应区域验收。
R-15 另覆盖旋转/裁剪页面的扫描覆盖率计算，禁止对不同坐标空间直接求面积；这是内部风险判断，不要求展示坐标转换。
R-14 只验证独立调用不变性；失败恢复、强制执行和历史产物保留需要后续存储/Runner 用例。
