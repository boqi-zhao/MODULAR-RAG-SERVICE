1. 先准备公开样本校验和、控制 PDF 配方和测试代码，业务解析模块尚不存在。

## 验证命令

```sh
uv sync --locked
uv run pytest -q
uv run ruff check .
uv run ruff format --check .
```

测试标记为 `public_pdf`、`controlled_pdf`、`fault_injection`，可按标记单独运行。
PyMuPDF 导入时有第三方 SWIG 弃用提示；当前测试无失败或跳过。

## 本轮完成边界

实现的是独立 Python 解析模块和完整返回结果；调用方式见 [使用说明](../../05-pdf-parse-usage.md)。
产物版本落盘、Runner、HTTP 接口与 worker 尚未实现；chunk 仍未开始。
这些结果不代表通用解析准确率，也不代表 10 用户并发已验证。
