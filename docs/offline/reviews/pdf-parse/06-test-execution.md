## 6. 测试数据与运行要求

- 提交小型来源/校验和清单和经核对的预期，PDF/JSON 原始样本暂按既有规则保留在忽略的 data 目录。
- 开发时正式选用的公开样本须先核对 SHA-256；缺失/被修改要明确报准备错误，不能静默 skip 后宣称全套通过。
- 跨机器执行时须恢复这份固定字节清单；补齐可复现下载步骤后才能把公开样本回归作为 CI 必需检查。
- 本组单元/受控测试不能依赖 PostgreSQL、网络模型或 HTTP 服务；真实 PDF 回归运行时也不请求 OCR 服务。
- 先写针对外部行为的失败测试，确认因缺少 parse 能力而失败；不能以坏依赖/缺失数据冒充 Red。
- 按能力分小步实现，通过后运行相关 pytest、Ruff 检查和格式检查；不为内部实现写镜像测试。
- 记录正常/失败样本、阈值与失败原因；不使用这 20 页发布通用解析准确率或并发能力数字。
