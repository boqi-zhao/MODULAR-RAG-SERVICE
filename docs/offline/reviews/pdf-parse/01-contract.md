## 1. 本组已确认的输入输出

以下业务内容仅约束本次 parse；具体返回对象和字段名在分步重写时讨论，见 [解析计划](../../05-pdf-parse-plan.md)。
不引入所有 Stage 的 schema，不把 PDF 页码作为未来所有格式的共同要求。

| 项目 | 已确认约定 |
| --- | --- |
| 输入内容 | 固定的原始 PDF 字节；原文件不改写，不按路径推断身份 |
| 服务内部解析配置 | 由服务提供默认的扫描风险判断参数，用户上传时无需填写；记录本次实际使用值 |
| 来源校验 | 从实际输入计算 SHA-256，用于原始内容校验；与逻辑文档 ID（document_id）分开 |
| 解析结果 | 成功或失败；已知页数、逐页处理记录、文本块、图片字节与每次出现的位置 |
| 来源位置 | 本 PDF 页序、PyMuPDF 返回的文本块/图片原始矩形、页尺寸 |
| 诊断 | 规则/错误类别、原因、能确定的页和对象、观察值；未知位置留空，不伪造 |
| 复现信息 | 记录解析库版本和实际使用的配置，方便重跑与比较；执行时间、耗时等信息单独记录 |

结果可在解析文件关闭后继续读取，不能含依赖已关闭 PDF 的懒加载对象。
用户只需上传 PDF，服务自动检查密码限制和扫描风险；首批不支持密码解密与 OCR。
失败也返回已取得的内容和诊断；失败结果不满足正常下游输入资格。
输入字节损坏或需要密码时明确失败；配置错误在解析前拒绝，不混同为文档质量失败。
不读公开样本的配套 JSON 来补充被测 PDF 的文字或图片。
