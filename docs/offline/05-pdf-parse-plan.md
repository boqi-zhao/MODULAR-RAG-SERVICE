# PDF 解析分步重写安排

状态：原实现已删除，以下仅为后续讨论顺序，不是已经可用的调用说明。
需求以 [首批评审入口](reviews/01-pdf-parse-cases.md) 为准，开发采用 [分步讲解流程](01-development-flow.md)。

## 建议逐步理解的内容

| 小步骤 | 要讲清楚什么 | 怎么核对结果 |
| --- | --- | --- |
| 打开 PDF 与读取文字 | 文件如何打开、如何逐页读取、文本块是什么 | 查看一页真实 PDF 的文字和页码 |
| 保留原始位置 | 文本块的坐标来自哪里、为什么要保留 | 与 PDF 页面上文字的大致位置对照 |
| 提取图片 | 图片字节与图片出现位置的区别 | 打开提取图片，核对同图多次出现 |
| 记录问题 | 打不开文件、局部失败和扫描风险如何区分 | 查看问题页和其他页保留的结果 |
| 整理返回内容 | 下游如何读取统一结果、重复调用如何保持独立 | 调用两次，核对结果不重复追加 |

每次只实现双方确定的小步骤；完成后展示代码逻辑与实际结果，再决定下一步。
具体类名、方法名和字段名在对应步骤讨论，不沿用已删除代码作为既定实现。

## 外部怎么调用

底层解析模块由 Python 调用；外部客户端需要通过 FastAPI HTTP 接口使用服务。
上传、任务提交、进度与结果查询属于接口层，需要单独说明并确认具体行为。
已实现服务入口和 `GET /health`，见 [第一步接口说明](api/01-service-entry.md)。
已评审的 PDF 用例没有确定上传和解析的 HTTP 路由，后续逐步讨论并实现。
