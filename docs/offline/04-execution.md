# 从指定阶段执行与调优

2026-10-07 用户已评审通过调优流程、Stage 交接和验收要求；Runner 尚未实现。
本页合并原“04 流水线调优”与执行草案；操作目标已确认，任务表、租约、接口和调度细节仍待评审。

## 核心流程

```text
首次：上传 U → parse 策略 A / 产物 P1 → chunk C1 → 索引 I1
调优：复用 U → parse 策略 B / 产物 P2 → chunk C2 → 索引 I2
比较：固定评测集和评测配置，比较两份实验
```

U 不重新上传，P2 不覆盖 P1，C2 必须读取 P2；I1 保留，I2 独立保存。
只改 chunk 时复用指定 P1，parse 不重算。每个小 Stage 先满足 [03 产物约束](03-stage-artifacts.md)。
“策略”包括实现和有效参数，也包括影响输出的模型/Prompt/依赖版本；不限于一个阈值。

1. 选基线和目标 Stage，固定全部上游版本，新建实验计划并固定下游策略。
2. 校验可复用上游，执行目标阶段，再按依赖图重跑受影响后继。
3. 汇合分支用本次新结果和指定的未受影响旧结果，检查契约兼容；不读取“最新”。
4. 保存新旧版本及实验关系；失败阻断依赖它的下游，旧实验仍可读取。

多文档索引只替换选中文档在新语料中的版本，保留其他成员；不能丢掉未调优文档。
新策略须输出兼容契约，不兼容则升级契约并适配下游。先做已有实现，不要求提前搭动态插件框架。
解析读取已有固定原文件，不能绑定一次上传请求；当前路径接口见 [02](02-pdf-parse.md)，正式版本绑定由后续执行层完成。

## 四种操作要分清

| 操作 | 执行范围 | 输入与结果 |
| --- | --- | --- |
| 单阶段执行 | 仅指定节点 | 完整固定上游；不自动补依赖或更新下游 |
| 下游重跑 | 指定节点和受影响后继 | 新计划；后继读新结果，其余依赖固定旧版本 |
| 失败恢复 | 原计划未完成节点 | 原配置/输入不变；成功产物校验后保留，失败/中断新建尝试 |
| 强制执行 | 以上范围中指定节点 | 绕过复用并生成新产物；是否执行后继由范围决定 |

范围和复用政策是独立选项。更改参数、实现或输入属于新计划，不能叫原任务恢复。
恢复先以整个 Stage 为单位，不承诺页内/批次断点；成功上游不覆盖，独立分支成功结果保留。
只执行 dense 不自动执行 sparse，旧组合索引仍绑定旧结果，新组合要单独构建。
任务计划固定根输入、配置、可选节点、已有引用和依赖图；新上游成功后一次记录引用，重试不改成最新版本。

## worker 与状态：待评审

API 接收任务并返回引用，独立 worker 执行长任务；不让 HTTP 请求等待整个流水线。
现有建议用 PG 任务表，短事务 `FOR UPDATE SKIP LOCKED` 领取并登记所有者、租约和递增 token，随后释放事务。
续租与提交条件检查所有权；超时旧进程可能仍在算，租约只控制提交资格，不保证计算或模型计费只发生一次。
记录错误、尝试数、next_attempt_at 和退避；依赖就绪时事务登记后继，定期对账补漏调度。
任务表派发，Runner 决定依赖/重跑；SKIP LOCKED 不能代替公平调度。队列选型尚未最终批准。

尝试状态建议为 `queued → running → succeeded / failed / interrupted`；校验失败属于 failed。
复用记节点 reused 和来源 artifact_id，不伪造实际尝试；历史尝试和状态事件追加保留。
任务聚合 queued/running/succeeded/failed：仍有分支运行时保持 running；恢复可再次 queued/running。
查询展示输入版本、尝试历史、复用来源、产物、耗时、错误及关联日志；取消协议另行设计。

## 已确认的集成验收

| 场景 | 必须证明 |
| --- | --- |
| 一次上传、两种 parse 策略 | 固定同一原文件，两份结果均可读，没有新上传 |
| 更换 parse / 仅更换 chunk | 受影响下游绑定新版本；未受影响上游没有新执行 |
| 调优失败 | 失败部分不发布为成功上游，旧实验可用 |
| 退出后新进程读回 | 正文、图片及版本信息完整，下游不用重算该 Stage |
| 固定版本缺失/损坏 | 指出版本/文件并拒绝，不静默替换 |
| 比较实验 | 固定评测集、在线/评测配置，报告各阶段真实版本与变化 |

另需演练发布文件后 PG 登记前崩溃、worker 被接管后旧进程返回、独立分支部分失败及恢复。
这些是存储/Runner/评测的集成验收，当前解析重复调用与 JSON 读回不能替代。
