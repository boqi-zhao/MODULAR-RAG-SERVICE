# 撤回由单个 PDF 触发的图片兼容处理

日期：2026-10-07。任务：T-11。类型：兼容处理撤回。
决定：用户要求 review 并去掉针对某个 PDF 的特殊优化；已撤回，未提交。
基线与选型见 [02 解析选型](02-pdf-parser-selection.md)，实现说明见 [C 步](../history/offline/01-pdf-history.md)。

## 1. 问题与原处理

C 步曾在本机某份 PDF 中发现：图片出现清单的像素摘要与导出 CMYK JPEG 独立解码的摘要不同。
为使该样本匹配通过，追加了三项处理：请求 xref，核对 PDF 资源字节作为匹配兜底，有 xref 时改用 PDF 资源解码。
此前称其为“通用修正”，因为源码没有文件名分支；这个判断不充分，追加处理实际由单个样本的问题触发。
这不能替代独立的通用性论证和用户调优评审，因此按用户要求撤回。

## 2. 当前统一行为

- 所有图片都从 dict 图片块取得主图字节与遮罩，不切换到 xref 资源读取。
- 两份清单统一按尺寸、变换位置和像素摘要核对；不一致则 image_position_failed，不降低匹配条件。
- 保留已知图片位置、其他图片和文字，以及后续页；失败出现不提供可用资产引用。
- 原始矩形、跨边界完整图片、内联图、透明度、重复出现和 PNG 输出属于已评审要求，继续保留。
- 实现版本由 0.1.0-dev-c 改为 0.1.0-dev-c2；扫描与正式持久化仍未完成。

## 4. 面试讲述

实现解析基线时曾为单个样本加入图片兼容处理，review 后撤回，保留问题与历史证据。
基线采用一致的提取与失败规则；兼容与调优单独评审，用独立输入验证机制，避免围绕已知样本反复补丁。
