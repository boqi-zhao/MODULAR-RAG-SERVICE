# 评测阶段

状态：待设计。本轮不实现评测。

后续范围：评测集版本、证据标注、检索指标、答案指标、实验对比及回归报告。
具体指标定义、裁判配置、证据命中阈值和报告格式在本阶段设计时确定。

与其他阶段的交接约束：

- 一次评测固定评测集、语料快照、索引快照及在线配置版本。
- 结果记录涉及的阶段产物和模型版本，禁止运行时隐式解析为最新版本。
- 同一分块方案可使用 chunk ID 标注；跨分块方案对比以文档版本及原文证据范围为依据。
- 不同解析方案之间的证据映射需要独立规则；没有可靠映射时，不宣称标注可直接复用。
- BM25 对比固定完整语料范围；记录语料变化，避免把统计变化误认为检索算法改进。

离线版本与证据规则见 [离线设计草案](../offline/README.md)。
