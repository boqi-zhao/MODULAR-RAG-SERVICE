# 在线检索阶段

状态：待设计。本轮不实现在线检索。

后续范围：查询预处理、Dense/Sparse 召回、过滤、融合、精排、上下文组织与答案生成。
具体模块、接口、模型和降级策略在本阶段设计时确定。

与离线阶段的交接约束：

- 请求读取一个明确、完整、已校验的索引快照，不混合两个快照的 Dense/Sparse 数据。
- 返回的 chunk ID 可追溯到块集合、文档版本及原文证据位置。
- 保存检索使用的索引快照与在线配置版本，供问题排查和评测复现。
- 离线构建成功不自动切换在线流量；发布与切换策略留待本阶段设计。

离线交接产物见 [离线设计草案](../offline/02-design.md)。
